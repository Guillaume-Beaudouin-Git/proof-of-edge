# trend_futures_funnel — what is published here

Everything: `PREREG.md` (locked before data contact), `REPORT.md`, the engine (`engine.py`,
`metrics.py`, `dsr.py`, `trials.py`), the funnel scripts `funnel_p1_ic.py` … `funnel_p8_marginal.py`,
`verify.py`, the trial ledger `trials_log.csv`, result tables and figures.

The scripts expect the data lake described in the top-level README (`RESEARCH_DATA_ROOT`); without
it they cannot run, which is why they are not part of the test suite.
